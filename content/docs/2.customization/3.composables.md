# Composables

The template includes several composables to handle shared logic across the application. These composables provide reusable functionality for platform detection, navigation, user preferences, search, and color management.

## useIsMac

**File:** `app/composables/useIsMac.ts`

Detects if the user is on a macOS platform using a robust multi-layered check.

### Features
- Uses `navigator.userAgentData?.platform` (modern browsers)
- Falls back to `navigator.platform` and `navigator.userAgent` (legacy browsers)
- **SSR Safe**: Initialized to `false` and updated within `onMounted` to prevent hydration mismatches.

## useNavigation

**File:** `app/composables/useNavigation.ts`

Manages the transformation of Nuxt Content collections into a structured navigation format.

### Features
- Migrated to Nuxt Content v3 collection navigation (`queryCollectionNavigation`).
- **Automatic Categorization**: Heuristically determines item types:
  - `component`: Items under the "Components" parent.
  - `block`: Items under the "Blocks" parent.
  - `group`: Folders containing other items.
  - `page`: Standard documentation pages.
- **Filtering**: Specifically processes the `docs` stem.

The `NavigationItem` type it returns lives in `app/lib/navigation.ts`, not in this file — it's the same type used by `DocsSidebar`, `MobileNav`, `CommandMenu`, and `useSidebarSections`, so there's one navigation shape instead of one per consumer.

## useSidebarSections

**File:** `app/composables/useSidebarSections.ts`

Shapes a content navigation root into the two groups every nav surface renders: `rootPages` (optional pinned links) and `folderGroups` (the content tree). `DocsSidebar.vue` (desktop) and `MobileNav.vue` (mobile) both call this instead of each defining their own near-identical computeds, so the two surfaces can't drift out of sync.

### API
- `useSidebarSections(root: () => NavigationItem | undefined)`
  - `root`: Getter returning the root navigation item from `useNavigation()`.

### Returns
- `sectionsLabel`: Reactive string label for pinned quick links (defaults to `SIDEBAR_SECTIONS_LABEL`, e.g., `"Sections"` or `"Quick Links"`).
- `rootPages`: The top-level section pills, populated from `NAV_SECTIONS` and enriched recursively with icons and badges from matching pages in the content tree.
- `folderGroups`: The folders below them, excluding titles in `SIDEBAR_EXCLUDED_SECTIONS`, paths in `SIDEBAR_EXCLUDED_PAGES`, and automatically omitting any pages already pinned in `rootPages` to prevent duplicate links.

```ts
const { sectionsLabel, rootPages, folderGroups } = useSidebarSections(() => tree.value)
```

## useConfig (User Configuration)

**File:** `app/composables/useUserConfig.ts`

A shared state composable for managing user-specific preferences with cookie-based persistence.

### Persistent Preferences
- **Layout**: Switch between `"fixed"` and `"full"` width.
- **Package Manager**: Remembers preferred tool (`pnpm`, `npm`, `yarn`, `bun`).
- **Installation Type**: Preferred method (`cli` or `manual`).

### Reactive Behavior
- **Automatic Class Application**: Uses `watchImmediate` to apply `layout-{type}` classes directly to `document.documentElement` for styling inheritance.
- **sharedState**: Wrapped in `createSharedComposable` to ensure a single source of truth across components.

## useSearch

**File:** `app/composables/useSearch.ts`

A feature-rich search composable with debouncing, memoized results, and version tracking.

### Key Features
- **`ensureFreshCache`**: A pure, directly-testable function that owns cache freshness — it compares the previously seen docs version against the latest one (queried from `/api/docs-version`) and clears the search cache before adopting the new version.
- **Memoized Search**: Results are cached indefinitely per query via `useMemoize`, with no separate TTL — the server's own cache is already keyed by docs version, so `ensureFreshCache` is the single source of invalidation on the client.
- **Debounced Search**: Queries are debounced by 300ms to optimize performance.

### API
- `searchQuery`: Reactive string for the input.
- `searchResults`: Array of `SearchResult` objects.
- `isSearching`: Loading state boolean.
- `clearSearchCache()`: Manual trigger to reset cached results.

## useColors

**File:** `app/composables/useColor.ts`

Manages color format preferences and clipboard history.

### Configuration
Persistence is handled via the `color_config` cookie:
- **format**: Current display format (`hsl`, `rgb`, `hex`, or `oklch`).
- **lastCopied**: Stores the most recently copied color value.

### Return Values
- `isLoading`: `true` until the component is mounted (SSR safety).
- `format`: Computed current format.
- `setFormat(format)`: Updates the preference.
- `setLastCopied(color)`: Updates the history.
