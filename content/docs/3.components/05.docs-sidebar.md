The `DocsSidebar` component provides a navigation sidebar for documentation pages with section pills and a hierarchical page structure.


## Usage

```vue showLineNumbers
<script setup lang="ts">
import { DocsSidebar } from '@/components/DocsSidebar'
import type { NavigationItem } from '@/lib/navigation'

const tree: NavigationItem = {
  title: "Docs",
  path: "/docs",
  children: [
    {
      title: "Getting Started",
      children: [
        {
          title: "Introduction",
          path: "/docs/getting-started/introduction",
        },
      ],
    },
  ],
}
</script>

<template>
  <DocsSidebar :tree="tree" />
</template>
```

## Features

### Pinned Sections & Quick Links

The sidebar supports optional pinned quick links at the top, configured in `app/lib/navigation.ts`:

```typescript
export const SIDEBAR_SECTIONS_LABEL = "Sections"; // Or "Quick Links", "Featured"

export const NAV_SECTIONS: NavItem[] = [
  // Leave empty [] to only show the content folder tree without duplicate links
  // { name: "Demo", href: "/docs/prose-demo", icon: "sparkles" },
];
```

When `NAV_SECTIONS` is empty, this section is completely hidden. If items are added, `autoExcludeSectionsFromGroups: true` automatically ensures they aren't repeated in the content folders below.

### Navigation Tree

The sidebar automatically renders a navigation tree from your content structure:

- Groups pages by content directory (`content/docs/`)
- Uses directory numeric prefixes (`1.getting-started`, `2.customization`) for order
- Shows icons from frontmatter `navigation.icon`
- Supports custom sidebar titles via `navigation.title`
- Highlights the active page with accent background and border
- Supports status indicators (`new: true`, `beta: true`, `soon: true`)

Shaping the raw tree into section pills (`rootPages`) and folder groups (`folderGroups`) is handled by the shared `useSidebarSections(tree)` composable (`app/composables/useSidebarSections.ts`), so `DocsSidebar` and `MobileNav` stay in sync from one implementation instead of duplicating the logic. See [Composables](/docs/customization/composables#usesidebarsections) for details.

### Filtering

You can exclude sections or pages from the sidebar in `app/lib/navigation.ts`:

```typescript
// Exclude entire folder groups by title (case-insensitive)
export const SIDEBAR_EXCLUDED_SECTIONS: string[] = ["archive", "drafts"];

// Exclude specific pages by path
export const SIDEBAR_EXCLUDED_PAGES: string[] = ["/docs/prose-demo"];
```

Or simply add `hide: true` directly to any page's frontmatter.

## API Reference

### DocsSidebar

| Prop  | Type            | Description                          |
| ----- | --------------- | ------------------------------------ |
| `tree`| `NavigationItem` | Navigation tree from Nuxt Content    |

### NavigationItem

`NavigationItem` is the single shape shared across the content tree, `DocsSidebar`, `MobileNav`, and `CommandMenu`. It's defined once in `app/lib/navigation.ts` and re-exported wherever it's needed.

| Property    | Type                        | Description                             |
| ----------- | --------------------------- | --------------------------------------- |
| `title`     | `string`                    | Section or page title                   |
| `path`      | `string`                    | Route path                              |
| `children`  | `NavigationItem[]`          | Child navigation items                  |
| `navigation`| `{ title?: string; icon?: string }` | Navigation metadata (custom title/icon) |
| `new`       | `boolean`                   | Shows a green dot indicator             |
| `beta`      | `boolean`                   | Shows an orange dot indicator           |
| `soon`      | `boolean`                   | Shows a "Soon" badge                    |
| `hide`      | `boolean`                   | Hides the page from sidebar navigation  |

## Customization

### Styling

The sidebar uses Tailwind classes and can be customized:

- Sticky positioning at the top
- Scrollable content area
- Blur effects at top and bottom
- Responsive visibility (hidden on mobile, shown on desktop)

### Icons

Icons are displayed using the `LucideIcon` component. Set icons in your markdown frontmatter:

```yaml
---
title: My Page
navigation:
  icon: "book-open"
---
```
